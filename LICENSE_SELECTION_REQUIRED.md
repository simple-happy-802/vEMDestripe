# License selection required before public release

The supplied source files and manuscript do not identify a software license. A repository without a license is publicly visible but is not meaningfully open source: copyright law reserves reuse, modification, and redistribution rights by default.

The copyright holders should jointly choose an OSI-approved license before the first public GitHub release. Common options include:

- Apache License 2.0: permissive, explicit patent grant, preservation of notices;
- BSD 3-Clause: permissive and concise, with a non-endorsement clause;
- MIT License: short and permissive;
- GPL-3.0: reciprocal; derivative distributions must remain under GPL-compatible terms.

After author approval, replace this file with the full unmodified license text in a root-level file named `LICENSE`, add the copyright year and holder information where the selected license requires it, and ensure all bundled third-party code and model/data licenses are compatible.
