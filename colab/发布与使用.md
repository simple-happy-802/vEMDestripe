# Bumbarger13 演示

[打开 Colab 演示](https://colab.research.google.com/github/simple-happy-802/vEMDestripe/blob/main/colab/vEMDestripe_Bumbarger_Pipeline_Demo.ipynb)

1. 连接运行时，保持 `VEM_RUN_MODE = 'published_full_volume'`。
2. 选择“运行时 → 全部运行”。默认使用 CPU，资源包约 346 MiB。
3. 程序读取已保存的网络输出，执行推理后处理，再展示 XY、XZ、YZ 和指标表。
4. 在最后一个单元下载结果 ZIP，包含图像、指标和处理记录。

可选 `live_demo` 模式使用 GPU 对 32 张切片现场推理。默认模式使用完整 2651 层
网络输出的统计记录，两种模式均展示原生 Z 的同位置截面。具体数据来源与输出文件见
[演示说明](README.md)。

代码固定在 `optimized-inference-v1` 标签，数据来自 `demo-reference-v3` Release。
数据归属和基线来源见 [数据说明](DATA_LICENSE.md) 和 [方法说明](THIRD_PARTY_METHODS.md)。
