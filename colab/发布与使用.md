# 新版 Colab：发布与使用

新版为 `colab/vEMDestripe_Bumbarger_Official_Demo.ipynb`，仓库配置为
[simple-happy-802/vEMDestripe](https://github.com/simple-happy-802/vEMDestripe)，
分支 `main`。它默认展示**未经修改的官方 EMISAC 源码在固定旧环境中生成的结果**，

## 作者发布时需要哪些文件

1. 将新版 Notebook、配套模块、文档和 `colab/official_emisac/` 复现材料提交到仓库。
   仓库根目录直接包含 `README.md`、`infer.py`、`colab/`、`vemdestripe/`，
   不要再套一层 `vEMDestripe/`。
2. 确认现场推理所需的发布权重 `checkpoints/vemdestripe_seed42/best.pth` 可下载。
   没有 GPU 时，演示允许使用资源包中明确标记的 vEMDestripe 冻结输出。
3. 创建标签为 `demo-official-v2` 的 GitHub Release，上传
   `release_assets/vemdestripe_bumbarger_official_demo_v2.zip`。保持文件名不变。
   大型 H5、TIFF 和逐张图片放在 Release 资源包中，不放进普通代码提交。
4. Notebook 固定该资源包的 SHA256；若重新打包，应同时更新校验值，不能只替换附件。
   包内 `manifest.json` 还会校验每个文件。
5. 发布后，用新的 Colab 会话从头执行一次 **Runtime → Run all**，核对下载、
   文件校验、图像、两套指标、源码查看和导出。只有实际在托管 Colab 中运行过，
   才能声称通过了 Colab 端到端测试。

本说明列出发布步骤，不表示某次上传或 Release 已成功；实际发布结果以仓库和
Release 页面为准。项目自身的软件许可证仍需作者确认；
`LICENSE_SELECTION_REQUIRED.md` 不是许可证。第三方源码保留各自许可证。

## 读者怎样使用

1. 点击上面的链接并连接运行时。
2. 若要现场运行 vEMDestripe，选择 GPU 运行时，再执行 **Runtime → Run all**。
   仅查看已发布结果和计算指标可使用 CPU；页面会标明采用了冻结输出。
3. 等待资源包下载与完整性检查完成。**EMISAC 默认加载原版预计算结果，不在
   此 Colab 会话中现场优化。**
4. 用滑块查看 XY、XZ、YZ 图像和 Z 轴亮度曲线。默认 `Raw outputs` 不额外调整
   算法输出；`Global affine matched` 是单独标注的可选亮度匹配视图。
5. 查看重新计算的指标表，区分 raw 与 global-affine 两套协议，再从导出单元格
   下载结果 ZIP。Colab 临时文件可能在断开后丢失，应及时保存。

## 怎样确认 EMISAC 确实来自原版

资源包中的 `provenance/emisac_official/` 包含原始浮点 H5、实际输入 TIFF、
官方源码与许可证、运行日志、命令、依赖版本和元数据；`manifest.json` 提供校验值。
官方提交固定为 `7a82a17b7bbb4ca14dff2d1c1a4a018fc8cebaf5`，两个官方脚本未修改。
展示用 PNG 仅进行统一的四舍五入和 0–255 截断，没有逐片亮度拉伸。

原版复算方法见 [official_emisac/REPRODUCE.md](official_emisac/REPRODUCE.md)。
旧环境依赖与当前 Python 3 环境隔离；不要求读者通过修改 Colab 系统 Python 来运行。
当前运行参数明确关闭 Z 上采样，不能写成“原版所有默认参数”。记录的旧环境也不
代表已完全恢复作者当年的机器环境。

## 演示范围与来源

- 数据是本地编号 **777–808 的 32 张 1024×1024 切片**。EMISAC 原版此次直接处理
  这 32 张，不是完整体数据处理后截取。演示指标不能替代论文 200 张窗口指标。
- vEMDestripe：发布权重现场推理，或明确标记的冻结结果。
- EMISAC：固定官方源码与旧依赖环境的预计算输出，不是本地 GPU 改写版，也不是
  未通过真实数据数值等价测试的 Python 3 兼容版。
- FECNet：灰度 EM 适配并针对 Bumbarger 微调后的冻结结果，不能称为原版默认权重。
- SSCOR：对应测试体数据自监督训练后的冻结结果，不在此演示中重新训练。
- 其他方法的处理上下文以来源记录为准；显示相同 32 张不代表各方法原始输入体积
  都只有 32 张。
- 该真实数据没有逐片配对的干净真值，因此不报告 PSNR/SSIM；参考切片不是配对真值。

旧 `vEMDestripe_Bumbarger_Demo.ipynb` 保留为历史兼容版实验，不再推荐用于原版
EMISAC 效果展示。更多来源说明见 [THIRD_PARTY_METHODS.md](THIRD_PARTY_METHODS.md)
和 [DATA_LICENSE.md](DATA_LICENSE.md)。
