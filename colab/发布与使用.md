# 完整流程演示：发布与使用

[打开新版 Colab](https://colab.research.google.com/github/simple-happy-802/vEMDestripe/blob/main/colab/vEMDestripe_Bumbarger_Pipeline_Demo.ipynb)

## 读者操作

1. 打开链接，连接运行时，保持 `VEM_RUN_MODE = 'published_full_volume'`。
2. 点击“运行时 → 全部运行”。默认无需 GPU，下载约 346 MiB 资源包。
3. 等待完整性校验和输出阶段结束。vEMDestripe 使用完整 2651 张网络输出拟合的
   固定整卷映射，目标来自 11 张记录的原始参考切片；先保存最终 PNG/TIFF 再计算指标。
4. 默认 `Final pipeline outputs` 展示完整流程结果。`Network-only diagnostic`
   只切换 vEMDestripe 的中间结果，其他方法不变，也不改变主评估输入。
5. 查看 `metrics_final_outputs.csv` 对应表格和源码，点击最后的按钮下载结果 ZIP。

可选 `live_demo` 模式需要 GPU：网络现场推理 32 张，再对全部 32 张新输出做统一校准。
这是独立的 32 张演示体，不冒充论文 2651 张源统计。切换模式建议重开运行时。

## 流程边界

`网络输出 → vEMDestripe 专属整卷亮度/对比度校准 → 保存最终结果 → 只读评估`

- 源统计是全部输出切片像素，不是评分窗口或单切片。
- 目标是原始参考切片池的像素统计，不是均值融合图、分块图或测试输入。
- 统一 LUT 采用 float32 灰度级、截断后取整，再转 uint8，与给定导出程序一致。
- 其他方法不做这项校准；评估程序对任何方法都不做归一化或拟合。
- 真实 Bumbarger 无逐片配对干净真值，不报告 PSNR/SSIM。32 张指标不代替论文完整评估。

GitHub 推理代码同样更新：`infer.py` 目录模式默认保留 `network_raw/` 并把最终图像
写到输出目录根部，记录 `CALIBRATION.json`。已有完整网络输出可以用独立
`calibrate_volume.py` 处理，再让 `python -m evaluation.evaluate` 读取最终目录。
显式 `--no_photometric_calibration` 仅用于网络原始输出消融。
