# Bumbarger13 demo data attribution

The Bumbarger13 image data originate from the Open NeuroData volume:

```text
s3://open-neurodata/bumbarger/bumbarger13/image
```

The public source is licensed under **ODC-By v1.0**. The demo contains a small
derived subset and method outputs for that subset. Preserve this file with any
redistributed demo archive and cite both:

1. D. J. Bumbarger, M. Riebesell, C. Rödelsperger, and R. J. Sommer,
   “System-wide rewiring underlies behavioral differences in predatory and
   bacterial-feeding nematodes,” *Cell*, 2013.
2. Open NeuroData, <https://registry.opendata.aws/open-neurodata/> (include the
   date on which the data were accessed).

Dataset page: <https://neurodata.io/data/bumbarger13/>

The local demo interval is `z=[777,809)`, corresponding to public mip-0
`z=[887,919)`. The nominal public mip-0 XY region is
`x=[11164,12188), y=[11164,12188)`. Local images are transposed relative to
the public XY planes and retain the project's verified historical alignment.
